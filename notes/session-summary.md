# Session Summary

This study session focused on beginner-to-intermediate C++ coding practice through LeetCode-style problems.

## Topics covered

- `std::unordered_set`
  - `insert`
  - `count`
  - `find`
  - `contains`
  - `size`
  - why there is no index access
- `std::stack`
  - LIFO behavior
  - `push`, `pop`, `top`, `empty`
  - valid parentheses problem
- Strings
  - `std::string::substr`
  - `std::string` indexing
  - splitting strings with `std::istringstream`
- Arrays and vectors
  - in-place modification
  - write index pattern
  - removing duplicates
  - removing elements
- Linked lists
  - dummy node
  - pointer splicing
  - merging two sorted lists
- Binary search
  - midpoint calculation
  - insertion position
- Digit arrays
  - why converting to integer can overflow
  - plus-one carry handling

## Problems discussed

- Contains duplicate
- Valid parentheses
- Merge two sorted lists
- Remove duplicates from sorted array
- Remove element
- Implement `strStr`
- Length of last word
- Search insert position
- Plus one
