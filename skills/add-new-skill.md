# Skill: Add New Study Skill

Use this workflow when adding more learning habits to this repo.

## Steps

1. Create a new markdown file under `skills/`.
2. Give it a clear name, such as `review-old-errors.md`.
3. Describe when to use it.
4. Describe which tracker or note file should be updated.
5. Add an example.

## Suggested future skills

- `review-old-errors.md`: revisit recurring mistakes weekly.
- `track-complexity.md`: record time and space complexity for every solved problem.
- `track-patterns.md`: group problems by pattern, such as two pointers, binary search, stack, hash map.
- `daily-practice.md`: define a daily C++ study routine.
