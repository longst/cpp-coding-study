# Skill: Track Data Structures

Use this workflow when a new data structure or STL container is studied.

## When to update

Update `trackers/data-structures.md` when:

- A new container is introduced.
- A container's key functions are practiced.
- A new algorithmic pattern is connected to the structure.

## What to record

For each item, track:

- Status: Planned, Started, Studied, Needs review
- What to know
- Practice problems

## Examples

- `std::stack`: valid parentheses, monotonic stack
- `std::queue`: BFS, simulation
- `std::priority_queue`: top K, heap
- `std::unordered_map`: frequency count, two sum
