# C++ Coding Study

This repository is my local record for learning C++ through data structures and LeetCode-style problems.

## Goals

- Practice C++ syntax and STL containers.
- Track common mistakes and fixes.
- Track which data structures have been studied.
- Keep reusable notes, templates, and future learning skills in one place.

## Current focus

- Arrays and vectors
- Strings
- Linked lists
- Binary search
- STL containers:
  - `unordered_set`
  - `unordered_map`
  - `stack`
  - `queue`
  - `priority_queue`

## How to use this repo

1. Add each solved problem under `problems/`.
2. Record mistakes in `trackers/error-log.md`.
3. Update studied data structures in `trackers/data-structures.md`.
4. Add new study workflows under `skills/`.
5. Put reusable C++ snippets under `src/` or `notes/`.
